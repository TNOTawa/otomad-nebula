# v0.4 全片时序表征升级：设计契约

> 状态：进行中（v0.4 / v0.4.1 / v0.4.2 本轮交付；v0.5 自监督 Transformer 下一轮）
> 基准提交：`b92c80a`；本文件是所有实现任务的技术契约（写代码前先读完全文）。

## 1. 目标与范围

把“均匀抽 ≤5×8s 片段再平均”升级为“覆盖整条时间轴的分层表示”：

1. **完整覆盖**：不再有作品级片段数上限；最后一段必须结束于视频结尾；任意时间点至少被 1 个窗口覆盖；
2. **多尺度**：PE-AV 语义序列（8s 窗口）+ 高频音画事件（音频 100Hz、视频 30fps）+ 固定统计时间结构；
3. **分阶段交付**：
   - **v0.4**：完整覆盖编码（序列层），并生成 Full Mean 表征与星云；
   - **v0.4.1**：高频事件扫描（音频/视频/音画关系），事件时间轴可视化；
   - **v0.4.2**：Temporal Stats 表征（无需训练）与三种空间切换、邻域迁移分析；
   - v0.5：自监督 Temporal Transformer（本轮只预留数据接口，不做训练质量结论）。
4. **保留旧数据**：旧向量 / 旧片段 / 旧地图一律不迁移、不覆盖；旧 `embedding_version` 目录保持原样；
5. **不使用人工标签**：年份/排名/作者/时长等元数据不进入任何向量或 UMAP 输入；
6. 不宣称“逐帧语义理解”。PE-AV 仍是 16 帧稀疏采样，高频通道只补充节奏/运动/突变信息。

## 2. 版本与命名

| 概念 | 取值 | 说明 |
| --- | --- | --- |
| Encoder Version | `peav-small-16f`（+ revision/frames/preprocess） | PE-AV 检查点与预处理 |
| Sequence Version | legacy：`peav-small-16f__f16_clip8s_x5_48k`；全片：`peav-small-16f__f16_full8s_ov0_48k`，336p 实验加 `_h336` | 全片窗口/时间索引/切片参数 |
| Event Version | `events_v1` | 事件扫描算法版本，记录在事件文件与表征参数中 |
| Representation | `legacy_5clip_mean` / `full_mean_v1` / `temporal_stats_v1` / `transformer_v1` | 聚合器版本；绑定 sequence_version |
| Map Version | `map_vNNN` | 每次拟合新版本，不覆盖 |

- `Config.embedding_version` 按 `sampling.mode` 返回当前激活的 sequence version；`Config.legacy_embedding_version` 永远返回旧公式，供 Legacy 空间定位。
- 同一版本参数必须一致（现有 `register_embedding_version` 规则沿用）；聚合器变化只产生新 representation，**绝不重新编码 PE-AV**。
- 不同 sequence / representation 的向量禁止混入同一 UMAP 输入；不同地图坐标不可跨空间比较绝对位置。

## 4. v0.4 全片采样（nebula/sampling.py）

新增独立纯函数，**不要**修改 `plan_clips()` 语义（保留旧行为与旧测试）：

```python
@dataclass(frozen=True)
class CoverageClip:
    index: int
    start_s: float
    duration_s: float          # 窗口长度（<= clip_seconds；仅整片短于 clip 时更短）
    valid_duration_s: float    # 有效时长（用于权重；正常等于 duration_s）
    weight: float              # 该窗口在整部作品时间轴上的权重份额，∑weight = 1
    @property
    def end_s(self) -> float: ...

def plan_full_coverage(duration_s: float, *, clip_seconds: float = 8.0,
                       overlap_seconds: float = 0.0,
                       min_duration_seconds: float = 1.0) -> tuple[CoverageClip, ...]
```

算法（确定性、无随机数）：

1. 校验同 `plan_clips`，另外要求 `0 <= overlap_seconds < clip_seconds`；
2. 若 `duration_s <= clip_seconds`：单窗口 `[0, duration_s]`，weight=1；
3. 否则令 `delta = duration_s - clip_seconds`、`step_max = clip_seconds - overlap_seconds`、
   `n = ceil(delta / step_max) + 1`；`step = delta / (n-1)`；
   `start_i = i*step`（i=0..n-2，四舍五入到 0.001s），`start_{n-1} = duration_s - clip_seconds`（精确锚定结尾）；
4. 每个窗口 `duration_s = clip_seconds`（最后一个精确结束于结尾），保证：无未覆盖间隙、无越界；
5. 权重：把时间轴按所有 start/end 切成段，每段覆盖计数 c(t)=覆盖它的窗口数，窗口 i 的权重 =
   `(∫_{窗口i} 1/c(t) dt) / duration_s`，四舍五入到 1e-9；测试要求 ∑weight=1±1e-6，且每一秒总权重=1；
6. 180s 默认参数 → 23 个窗口；40s → 5 个（与旧版恰好重合是巧合，不得作为假设写入代码）。

`nebula/media.py` 的 `extract_clip` 泛化为接受 `CoverageClip | ClipPlan`（两者都有 index/start_s/duration_s）；新增可选 `media.clip_height`（int|null）：非空时在视频滤镜中加 `scale=-2:{height}`，只影响视频切片；版本号必须带 `_h{height}` 后缀。

## 5. 全片编码流水线（nebula/pipeline.py）

- `Pipeline(config, sampling_mode=None)`；`sampling_mode ∈ {legacy, full_coverage}`，默认取 `config.sampling.mode`；CLI `pipeline.py run --sampling full` 覆盖。
- 版本号：legacy 沿用现有 `CLIP_SUFFIX` 公式与参数；full 使用 `..._full{clip:g}s_ov{overlap:g}_{sr}k[_h{height}]`，`embedding_versions.clips_per_work=0`（表示不限片段数），params_json 记录 `sampling_mode/full_coverage/overlap_seconds/clip_height/event_version/aggregation`。
- `_process_work` full 分支：
  1. 已 completed 的重新处理走 `reopen`（现有逻辑）；
  2. 本地作品直接用原文件；Bilibili 若 `temp/work_XXXXXX/download/` 已有可 probe 的源文件则跳过重新下载（崩溃恢复优化）；
  3. probe 一次；`plan_full_coverage`；写 `sequence_states(status=in_progress)` 与 `.partial/plan.json`（duration、窗口列表、sampling 参数、event 版本）；
  4. 若 events 开启且 `event_scan.npz` 不存在：`events.scan_events(source, plans, ...)` → `events.save_events_bundle(work_dir, ...)`；耗时记入 `events_s`；
  5. 按 `model.batch_size` 分批：只对缺失 batch 提取片段（每批提取→编码→写 `batch_{k:04d}.npz`→删除该批临时切片→更新 `n_clips_done`）；批文件内保存 joint/audio/video 数组；
  6. 全部完成后按 index 拼接，校验 hop 时间单调、覆盖完整；原子写 `clip_*.npy`、`clip_times.npy`、`work_*.npy`、`manifest.json`；
  7. `catalog.replace_clips`（5 元组：idx,start_s,duration_s,valid_duration_s,weight）→ `register_embedding` 六种 kind → `sequence_states(status=assembled, n_clips_done=n_clips)` → `complete` → 删除 `.partial` 与 temp；
  8. 失败：留下 `.partial` 与 temp，状态 failed；再次运行时按 plan.json 校验后从缺失 batch 继续（源文件时长/窗口不一致则丢弃 partial 重来）。
- 计时：`work_timings.events_s` 新增列；perf CSV 同步新增列；批次总耗时与单部耗时继续记录。
- 超长视频：`duration_s > config.media.long_video_seconds`（默认 3600）时 full 模式默认**不自动处理**：记 `failed`，错误信息明确提示需 `--allow-long` 显式启动；`--allow-long` 时照常全片处理。禁止静默截断。
- legacy 模式行为与现有完全一致（除新列默认值），现有测试必须继续通过。

## 6. v0.4.1 高频事件扫描（nebula/events.py，新文件）

```python
EVENT_VERSION = "events_v1"
AUDIO_FEATURE_NAMES: tuple[str, ...] = (...)  # 6 维
VIDEO_FEATURE_NAMES: tuple[str, ...] = (...)  # 6 维
AV_FEATURE_NAMES: tuple[str, ...] = (...)     # 6 维
WINDOW_FEATURE_NAMES: tuple[str, ...] = (...) # 32 维，固定顺序

@dataclass(frozen=True)
class EventFeatures:
    audio: np.ndarray          # (n_a,6) float32 @ audio_rate_hz（100Hz）
    video: np.ndarray          # (n_v,6) float32 @ video_fps_effective（默认 30）
    av: np.ndarray             # (n_a,6) float32 @ audio_rate_hz
    window_features: np.ndarray# (T,32) float32，与 CoverageClip 一一对应
    audio_rate_hz: float
    video_fps: float
    video_fps_effective: float
    duration_s: float
    version: str

def scan_events(source: Path, plans: Sequence[CoverageClip], *, ffmpeg: str = "ffmpeg",
                audio_rate_hz: int = 100, video_fps: int = 30,
                timeout_s: float = 600.0) -> EventFeatures
def save_events_bundle(work_dir: Path, features: EventFeatures) -> None
def load_events_bundle(work_dir: Path) -> EventFeatures | None
```

实现要求：

- 音频：ffmpeg 解码 48k 单声道 f32 → numpy STFT（win 25ms / hop 10ms）：rms、log_energy、spectral_flux、onset_strength（flux 正半波）、spectral_centroid_norm、spectral_flatness；无音轨用静音。
- 视频：ffmpeg `fps=30,scale=96:54,format=gray` → rawvideo 流；帧差均值、运动能量、边缘变化、亮度均值/标准差、cut 指示（阈值 = max(0.15, 3×median 帧差)，确定性）；`video_fps_effective` 记录实际采样率。
- 音画关系：视频 6 维特征线性重采样到 100Hz 网格；音频 onset 包络与视觉运动包络做 ±0.3s（±30 步）归一化互相关：最大相关、最优滞后、0 滞后相关、重合事件率、包络相关、事件率差。**不把高同步定义为更好**，只记录关系结构。
- 窗口压缩：每个 `CoverageClip` 覆盖的时间段内取上述序列统计（mean/std/p90、事件率、cut 率、闪烁率、自相关节奏强度等），固定 32 维；窗口与 plans 顺序一一对应。
- 全片一次连续解码（音频一条、视频一条 ffmpeg 命令），禁止逐片段重复扫描；单部作品事件扫描目标 <8s（3 分钟 480p）。
- 事件文件内部记录 version/rates/feature names；`event_features.npy` 为 window_features 的便捷副本。
- 失败（无视频流等）必须抛 `MediaError`/新 `EventScanError`，由 pipeline 记失败，不得静默写零向量。

### 7.2 `nebula/temporal.py`（t5）

```python
def assemble_full_mean(seq: ClipSequence) -> dict[str, np.ndarray]        # joint/audio/video
def assemble_temporal_stats(seq: ClipSequence, *, stages: int = 4) -> dict[str, np.ndarray]
```

- Full Mean：对每个模态 `normalize(z_i)` 的（不加权）算术平均再 L2 归一化；与旧聚合公式一致，作为“完整覆盖”单一变量基线。
- Temporal Stats（每个模态独立构造；events 块只进 joint）：
  - G1 semantic_global：加权均值（按 `weight`）→ L2，dim 1024，权重 1.0；
  - G2 stages：4 个相对时间阶段（按窗口与阶段区间的重叠时长加权）各求均值→L2，按阶段顺序拼接→整组 L2，dim 4096，权重 1.0；
  - G3 drift：`normalize(mean(后半) - mean(前半))`，dim 1024，权重 0.8（对顺序反转敏感）；
  - G4 dynamics：相邻片段的 cos 统计量（mean/std/min/max/q10/q50/q90、cos<0.5 比例、间隔 2/4 的 cos 均值、‖差分‖ mean/std/max），dim 12，权重 0.6；
  - G5 self_similarity：lag ∈ {1,2,3,4,6,8,12,16} 的平均 cos（无有效对填 0），dim 8，权重 0.5；
  - G6 events（仅 joint，若事件存在）：32 维窗口特征在整片 mean/std + 4 阶段均值 = 192 维；权重 0.8；无事件时整个表征使用 semantic-only 变体（同名但 params 记录 `has_events=false`，禁止与有事件版本混用）。
  - 每组先 L2 归一化再乘组权重；拼接后整体 L2 归一化。确定性与顺序敏感性由测试保证。
- 缺少音轨/单模态缺失：该模态向量不生成（该作品该 kind 跳过），joint 必须存在。
